# 小满记账 v2.0 — 产品需求文档 (PRD)

---

## 1. 产品定位

### 1.1 一句话描述
一款面向学生和年轻上班族的智能记账 App，解决"记账太麻烦"、"微信支付宝账单割裂"、"存钱缺乏规划"三大痛点。

### 1.2 目标用户

| 用户画像 | 特征 | 核心诉求 |
|---------|------|---------|
| 大学生 | 月生活费 1500-3000，餐饮占大头 | 想知道钱花哪了，别超预算 |
| 年轻上班族 | 月薪 6k-15k，想存钱但执行力差 | 自动化记账，存钱目标可视化 |

### 1.3 与竞品差异

| 功能 | 鲨鱼记账 | 随手记 | 钱迹 | 小满记账 |
|------|---------|--------|------|----------|
| 基础记账 | ✓ | ✓ | ✓ | ✓ |
| 3 级分类 | ✗ | ✓ | ✗ | **✓** |
| AI 语音记账 | ✗ | ✗ | ✗ | **✓** |
| 微信支付宝同步 | ✗ | ✗ | ✗ | **✓** |
| 存钱目标系统 | ✗ | 弱 | ✗ | **✓** |
| 多格式导出 | 弱 | ✓ | 弱 | **✓** |

## 2. 核心功能列表

### 2.1 基础记账（P0）

- 三种交易类型：支出 / 收入 / 存钱
- **3 级分类体系**（共 60+ 预设分类）

```
支出 → 餐饮 → 午餐/晚餐/零食/奶茶咖啡/水果/外卖...
     → 交通 → 地铁公交/打车/加油/高铁火车...
     → 购物 → 衣服鞋帽/电子产品/超市杂货...
     → 娱乐 → 电影演出/游戏氪金/旅行旅游...
     → ...（共 11 个一级分类）

收入 → 工资/奖金年终/兼职接单/理财收益/红包收入...

存钱 → 定期存款/基金定投/目标储蓄/应急金...
```

- 金额输入支持计算器模式（1+2+3=6）
- 编辑/删除记录（长按删除，滑动编辑）
- 备注、日期、来源标记

### 2.2 存钱模块（P1）

- 创建多个存钱目标（名称、目标金额、截止日期、图标）
- 进度条 + 存钱罐金币动画
- 自动存钱规则：
  - 每日固定金额
  - 每笔支出凑整存零头（花 18.5 → 自动存 1.5）
  - 每周/每月定投
- 完成目标后的庆祝动画

### 2.3 AI 语音记账（P1）

```
长按麦克风 → 说话 → 语音识别 → NLP 语义解析 → 自动填充 → 用户确认 → 保存
```

支持识别示例：
- "午餐吃黄焖鸡花了 22" → 支出-餐饮-午餐 ¥22
- "刚刚打车 15 块 5" → 支出-交通-打车 ¥15.50
- "存 500 到旅行基金" → 存钱-目标储蓄 ¥500
- "今天发工资 8000" → 收入-工资 ¥8000

### 2.4 微信/支付宝账单同步（P2）

**Phase 2：手动导入 CSV**
- 用户从微信/支付宝导出账单 CSV
- App 解析 → 自动匹配分类（"美团"→外卖，"滴滴"→打车）
- 去重合并（与已有记录比对）

**Phase 3：通知监听**
- Android：Notification Listener 自动捕获支付通知
- 匹配商户名 → 自动创建记账记录

**Phase 4：SDK 接入**（需企业资质）
- 支付宝开放平台 API
- 微信支付商户 API

### 2.5 数据导出（P1）

| 格式 | 用途 |
|------|------|
| CSV | Excel 打开，数据分析 |
| PDF | 打印、报销 |
| JSON | 数据备份、跨平台迁移 |
| 图片 | 月度记账卡片，社交分享 |

- 支持自定义导出范围（月份/分类/日期段）
- 大文件异步生成 + 下载链接

### 2.6 预算提醒（P2）

- 月度总预算设置
- 分类预算设置（如餐饮每月 1000）
- 超支推送通知

## 3. 用户使用流程

### 3.1 首次使用

```
下载 App → 注册/登录 → 闪屏引导
→ 进入首页（空白状态）
→ 点击「记一笔」→ 选择类型 → 选择分类 → 输入金额 → 保存
→ 首页月结余卡片更新 → 继续记账
→ 月底查看统计 → 导出账单
```

### 3.2 核心操作流程

```
┌─────────────────────────────────────────────┐
│                   首页                       │
│  ┌─────────┐ ┌────────┐ ┌─────────┐       │
│  │月结余卡片│ │收支对比│ │最近流水  │       │
│  └─────────┘ └────────┘ └─────────┘       │
│       │           │          │              │
│       ▼           ▼          ▼              │
│  ┌─────────┐ ┌────────┐ ┌─────────┐       │
│  │  统计页  │ │ 记账页  │ │ 流水页   │       │
│  │         │ │        │ │ 筛选     │       │
│  │月度趋势  │ │手动录入 │ │ 编辑     │       │
│  │分类占比  │ │语音录入 │ │ 删除     │       │
│  │年度对比  │ │支付导入 │ │ 导出     │       │
│  └─────────┘ └────────┘ └─────────┘       │
│                                            │
│  ┌─────────────────────┐                   │
│  │       存钱页         │                   │
│  │ 目标卡片 进度条       │                   │
│  │ 存钱按钮 自动规则     │                   │
│  └─────────────────────┘                   │
└─────────────────────────────────────────────┘
```

### 3.3 语音记账流程

```
首页 FAB → 长按麦克风按钮
→ 录音动画（波形跳动）
→ 松开 → 上传音频
→ AI 识别 → 返回结果弹窗
→ {类型:支出, 分类:午餐, 金额:22.00, 备注:吃黄焖鸡}
→ 用户可修改任意字段
→ 点击「确认」保存
→ Toast "已记录" + 首页刷新
```

### 3.4 账单同步流程

```
设置 → 账单同步 → 选择来源（微信/支付宝）
→ 选择 CSV 文件
→ App 解析 CSV → 显示待导入列表
→ 自动匹配分类（用户可修改）
→ 检测重复（已有记录高亮标记）
→ 用户选择：全部导入 / 跳重复 / 手动挑
→ 确认导入 → 批量写入
→ 完成提示："已导入 23 条，跳过 5 条重复"
```

## 5. 非功能性需求

| 类别 | 要求 |
|------|------|
| 冷启动 | < 2 秒 |
| API 响应 | < 200ms (P95) |
| 离线可用 | 本地 SQLite 缓存 |
| 数据安全 | 全链路 HTTPS + JWT 认证 + 密码哈希 |
| 崩溃率 | < 0.5% |
